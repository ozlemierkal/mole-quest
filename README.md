# Mole Quest — Prototype 0.1

İlk oynanabilir Mole Quest web prototipi.

## İçerik
- `index.html` — oyunun kendisi
- `assets/mole-quest-character.png` — ana karakter konsepti
- `assets/gameplay-concept.png` — oynanış görsel konsepti

## GitHub Pages ile yayınlama
1. GitHub'da `mole-quest` adlı yeni bir **Public** repository oluştur.
2. ZIP'i iPad'de Dosyalar uygulamasında aç ve klasörün içindeki dosyaları repo ana dizinine yükle. `index.html` repo kökünde kalmalı.
3. Repository içinde **Settings → Pages** bölümünü aç.
4. **Build and deployment / Source** alanında **Deploy from a branch** seç.
5. Branch olarak `main`, klasör olarak `/(root)` seç ve **Save** de.
6. Birkaç dakika sonra GitHub sana `https://KULLANICI-ADIN.github.io/mole-quest/` benzeri bir adres gösterecek.
7. Bu adresi Safari'de aç. Oyun dokunmatik yön tuşlarıyla çalışır.

## Prototype 0.1 oyun kuralları
- Yön tuşlarıyla köstebeği hareket ettir.
- Toprak blokları kazılabilir.
- Tüm mavi kristalleri topla.
- Kayalar aşağı düşebilir; altında kalma.
- Böceğe değersen bir can kaybedersin.
- Tüm kristaller toplanınca çıkış açılır.

Not: Bu sürüm mekanik test içindir. Sonraki sürümlerde karakter ve oyun dünyası görsel konseptteki stile yaklaştırılacaktır.
